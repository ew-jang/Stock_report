뉴스 심리 분석에서 실질 정보 밀도가 높았던 출처.

- 종합 경제지: 머니투데이, 파이낸셜뉴스, 서울경제, 이투데이, 서울신문
- 방송/속보: MBC(imnews.imbc.com)
- 반도체 전문: 디일렉(thelec.kr), ZDNet Korea, 테크월드(epnc.co.kr)
- 글로벌 반도체: KED Global, TrendForce, DigiTimes, Counterpoint, Tom's Hardware
- 시세/리서치: investing.com(kr), alphasquare, 키움 리서치(bbn.kiwoom.com), 유진투자증권

**How to apply:** 한국 종목(특히 반도체) 뉴스 수집 시 위 출처를 우선 신뢰. 인스타그램/블로그성 출처는 보조 참고로만 사용. 섹터 패턴은 [[sector-semiconductor-news-patterns]] 참고.
