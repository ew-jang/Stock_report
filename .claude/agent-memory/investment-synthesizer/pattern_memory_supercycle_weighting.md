메모리 반도체(삼성전자 등) **슈퍼사이클·완판 국면**에서는 뉴스 감성·업종 리서치 가중치를 상향하고, 신고가 직후 단기 조정(예: -8%)은 펀더멘털 훼손이 아닌 차익실현성 눌림목으로 해석해 감점을 최소화한다.

**Why:** 2026-06-28 삼성전자(005930) 종합 분석 시, "HBM 2026 물량 완판·선주문 2027년까지, 공급 정상화 2027년 이후"라는 구조적 수요 초과가 향후 18개월 실적 가시성을 확보했다고 판단. 이 경우 단기 가격 변동성보다 수주 가시성이 우위에 있어 조정이 매수 기회로 작동.

**How to apply:**
- 슈퍼사이클·완판 신호 확인 시 가중치: 재무 35→유지(우량), 뉴스 감성/업종 리서치를 상향 적용.
- 단, 메모리는 변동성 극심(2023년 삼성 영업이익 -85% 전력)하므로 **계약가(DDR5/HBM) 피크아웃**이 최우선 익절·손절 트리거. 가격 지표가 꺾이면 목표가 도달 전이라도 비중 축소 검토.
- 삼성 특이사항: SK하이닉스 HBM 1위·파운드리 약 7% 열위 → "슈퍼사이클 최대 수혜주"가 아닐 수 있는 구조적 리스크는 별도 감점 유지.
- 자사주 매입(삼성 최대 90조 거론) 공식화는 강력한 하방 지지선 → 추가 매수 비중 상향 근거. 외국인 순매도 가속·관세 현실화는 매수 보류 신호.
- 2026-06-28 판정: 총점 89/100 → 적극 매수. 목표 +30%(450,000원), 손절 -9%(314,000원), RR 1:3.3.
- **2026-07-11 후속 검증**: 2Q 영업이익 89.4조(어닝서프라이즈)로 "조정=매수기회" 테제 유효성 확인, 주가 ~346k→~390k 상승. 재판정 86/100 적극 매수 유지. 전 판정 로그는 [[verdict-log]] 참조.
