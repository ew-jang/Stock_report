메모리 반도체처럼 분기 실적이 몇 배씩 뛰는 국면에서는 **직전 회계연도(FY) 기준 단순 트레일링 PER은 왜곡**된다. FY2025 EPS 기준으로 계산하면 PER이 40배 안팎으로 나와 "고평가"처럼 보이지만, 실제 애널리스트들이 인용하는 PER(10~12배대)은 최근 분기 실적을 연환산(TTM 또는 QoQ 반영 연율화)한 값 기준이다.

**Why:** 삼성전자 2026년 1~2분기 영업이익(57.2조 + 89.4조)이 FY2025 연간 영업이익(43.6조)을 이미 넘어섬. 이런 실적 변곡점에서 스냅샷(FY) EPS를 쓰면 밸류에이션 판단이 완전히 반대로 나올 수 있음.

**How to apply:**
- PER 제시 시 (1) TTM/연환산 기준 PER과 (2) 직전 FY 기준 트레일링 PER을 함께 병기하고, 왜 차이가 크게 나는지 한 줄로 설명할 것("실적 급변 구간의 밸류에이션 역설").
- PBR은 자기자본이 최근 분기 순이익만큼 빠르게 늘어나는 구간이므로 BPS를 오래된 스냅샷으로 고정하지 말고 최근 유보이익 증가를 반영해 추정 범위로 제시.
- 시세(주가) 데이터는 검색 소스마다 인용 시점이 달라 20만원대~30만원대까지 큰 편차가 나타났음(2026-07 기준). 기사 발행일을 반드시 확인하고, 가장 최근 발행일 기사를 우선하며 "정확한 당일 종가는 확인 필요"로 flag.
- 관련: [[stock-samsung-005930-baseline]], investment-synthesizer의 `pattern_memory_supercycle_weighting.md`(밸류에이션 해석이 투자판단에 어떻게 연결되는지).
